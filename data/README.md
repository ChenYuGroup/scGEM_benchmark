# Data

The `./data/` directory contains the cell labels, model inputs and reference data used in the scGEM benchmark. The benchmark covers nine datasets: LUAD, PAAD, AML, T2D, BRCA, MESO, CellLines, ESC and SKCM.

## Directory contents

### `cell_labels/`

Contains the correspondence between cell identifiers and their assigned cell populations for each dataset, for example `cell_cellline_LUAD.xlsx`. These labels are used to evaluate the clustering performance of the reconstructed models.

All retained samples were included for PAAD and BRCA. For the other datasets, files such as `randomIndices_LUAD.mat` record the random sampling order or indices used to generate the analyzed subsets.

### `data_model/`

Contains the Human-GEM reference model and method-specific input files required for scGEM construction.


### `expression_matrices/`

The quality-controlled scRNA-seq expression matrices are available through [Zenodo](https://doi.org/10.5281/zenodo.21774476). After downloading and extracting the files, place them under `./data/expression_matrices/` in the accompanying GitHub repository.

The Zenodo record includes complete datasets and randomly sampled subsets, each provided as quality-controlled raw expression matrices (R) and matrices normalized using Linnorm and imputed using SAVER (LS). Here, R denotes expression data after quality control but before normalization and imputation, rather than raw sequencing reads.

The `LUAD.zip` file additionally contains expression matrices generated by perturbing the randomly sampled LS dataset to achieve a range of target Spearman rank correlations with the unperturbed matrix. These matrices are used for sensitivity analysis.

### `reference_data/`

Contains the reference datasets used for accuracy evaluation:

- `housekeeping_genes/`: three housekeeping-gene reference lists;
- `metabolic_tasks/`: a list of 57 essential metabolic tasks;
- `marker_genes/`: contains the marker-gene reference data:
    - `CellMarker 2.0.xlsx`: human cell-marker records obtained from the CellMarker 2.0 database;
    - `markerGene_dataset`: the correspondence between benchmark datasets or cell populations and the marker-gene sets used for evaluation; and
    - eight dataset-relevant marker-gene lists derived from CellMarker 2.0.
- `essential_genes/`: experimentally defined essential- and non-essential-gene lists. The DepMap Public 21Q3 and 22Q2 Achilles gene-effect matrices are not redistributed in this repository or the Zenodo record. They must be obtained separately from the [DepMap Data Portal](https://depmap.org/portal/data_page/) and saved as:

```text
./data/reference_data/essential_genes/Achilles_gene_effect_21Q3.csv
./data/reference_data/essential_genes/Achilles_gene_effect_22Q2.csv
```
